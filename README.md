# Установщик карт КрайКарт

Десктопное приложение для Windows и Linux, которое ставит карты с [kraimaps.ru](https://kraimaps.ru) в ваш лаунчер Minecraft: находит лаунчер, подбирает нужную версию игры и загрузчик, создаёт инстанс и раскладывает мир, моды и ресурспаки по папкам.

## Что это

Установщик — не лаунчер игры. Он решает одну задачу: избавить от ручной установки карты, когда нужно скачать архив, установить версию игры с загрузчиком, создать инстанс, распаковать мир, перекинуть моды и не забыть про ресурспаки. Здесь всё это делает одно приложение в 1 клик для вашего любимого лаунчера.
Для работы установщика нужен любой поддерживаемый лаунчер из списка.

## Что умеет

- **Установка с сайта в один клик.** Кнопка «Установить» на странице карты открывает приложение по ссылке `kraimaps://install/<id>`; установщик проверяет доступ к карте и показывает экран подтверждения.
- **Установка из файла.** Архив `.zip` или `.mrpack` с компьютера.
- **Автопоиск лаунчеров**, включая портативные версии.
- **Строгий подбор версии и загрузчика** по карте: ванилла, Fabric, Forge, NeoForge, Quilt. Ванильные карты можно ставить в нужную версию с любым загрузчиком.
- **Создание инстанса.** Если подходящего нет, установщик молча создаёт новый инстанс (Prism-семейство, Modrinth App) или готовит нужную версию игры (TLauncher, Legacy Launcher, официальный лаунчер).
- **Ничего не теряется.** Существующий мир с тем же именем не перезаписывается — установщик предложит новое имя. Заменённые моды и конфиги сохраняются в бекап в корне папки игры `.kraimaps-backup/<дата>/`.
- **Быстрая кнопка «Играть».** Prism-семейство запускается сразу в установленный мир, остальные открываются на нужной версии.
- **Иконка карты** становится иконкой инстанса при создании нового инстанса.
- **Понятные ошибки:** что случилось и что делать дальше, плюс «Подробнее» с техническим текстом для поддержки.
- **Автообновление установщика** с серверов КрайКарт с проверкой подписи сборки.

| Лаунчер | Как ставится |

## Скачать

- **С сайта:** [kraimaps.ru/installer](https://kraimaps.ru/installer) — основной рекомендуемый способ.
- **GitHub Releases:** [последний релиз](https://github.com/Dimatron74/KraiMaps_Installer/releases/latest) — файл `KraiMaps-Installer-<версия>-x64-setup.exe`. Рядом лежит `provenance-<версия>.zip` с подписью сборки и контрольными суммами SHA-256, если хочется проверить файл.

## Как поставить карту

1. Скачайте и запустите установщик. Приложение ставится в профиль текущего пользователя — права администратора не нужны.
2. Выберите способ: на странице карты нажмите «Установить» (нужен вход на сайт) или в приложении — «Выбрать файл с компьютера».
3. Проверьте карту, выберите лаунчер и нажмите «Установить».

## Сборка из исходников

Для тех, кто хочет собрать последнюю версию из репозитория.

### Что понадобится

- Windows 10/11 x64;
- Rust stable с MSVC-toolchain: `rustup default stable-x86_64-pc-windows-msvc`;
- Visual Studio Build Tools с рабочей нагрузкой «Разработка классических приложений на C++» и Windows SDK (нужны линковщик и системные библиотеки);
- Node.js 22+;
- pnpm 12 — версия зафиксирована в `packageManager` в `installer/package.json`, проще всего включить через `corepack enable`;
- WebView2 Runtime (в Windows 11 уже есть; для Windows 10 — [Evergreen Bootstrapper](https://developer.microsoft.com/microsoft-edge/webview2/)).

### Клонирование и запуск билда в деве

```powershell
git clone https://github.com/Dimatron74/KraiMaps_Installer.git
cd KraiMaps_Installer/installer
pnpm install
pnpm tauri dev
```

`pnpm tauri dev` поднимает приложение целиком. Если нужен только фронтенд с горячей перезагрузкой (без Rust-бэкенда) — `pnpm dev`, Vite слушает `http://localhost:1420`.

### Сборка установщика (как .exe файл)

```powershell
pnpm tauri build
```

Готовый установщик появится в папке `src-tauri/target/release/bundle/nsis/`.

### Про подпись обновлений

В конфиге включён `createUpdaterArtifacts`, поэтому Tauri требует приватный ключ подписи обновлений в переменной `TAURI_SIGNING_PRIVATE_KEY`. Для локальной сборки создайте свой:

```powershell
pnpm tauri signer generate -w $HOME\.tauri\kraimaps-dev.key
$env:TAURI_SIGNING_PRIVATE_KEY = "$HOME\.tauri\kraimaps-dev.key"
pnpm tauri build
```

### Что где лежит

- `installer/src/features/` — экраны визарда установки, авторизация, обновления;
- `installer/src-tauri/src/adapters/` — поддержка конкретных лаунчеров;
- `installer/src-tauri/src/services/` — поиск лаунчеров, деплой, скачивание, чистка временных файлов;
- `installer/nsis/` — оформление установщика (шаблон NSIS, перевод служебных строк, лицензионное соглашение, ассеты).
